Accessibility – NutriTrack

NutriTrack was designed with accessibility and usability in mind to ensure the application can be used by a wide range of users. The project follows general accessibility principles

Accessibility Features Implemented
-Clear Navigation
-The application uses consistent navigation bars and page layouts across the site.
-Important actions such as logging food, viewing recipes, and managing clients are clearly labelled.
-Routes are organised logically to reduce confusion for users.
-Readable Design
-A high-contrast dark theme with green highlights is used throughout the application.
-Text is displayed using readable font sizes and spacing.
-Cards and sections are clearly separated to improve readability.
-Form Accessibility
-Forms feature labels and placeholders to help users understand required inputs.
-Validation messages are displayed whenever incorrect or missing data is entered.
